## 错误级指标的四种口径（同一份 agent 输出，只换评分开关）

> ⚠️ **两根轴是正交的，别混**：
> ① **值比对**：`--string-compare`（`'0'` vs `'0.0'` 算不同）
> ② **旧开关**：`--no-recover-clean-key --keep-rows-not-in-gold`

| 口径 | 值比对 | 旧开关 | K29 mimicraw 4.7pct Det F1 | K29 mimicraw 4.7pct Rep F1 | 存档 |
|---|---|---|---:|---:|---|
| **v29（默认）** | 数值感知 | 保留 | **0.995626** | **0.978995** | `$RUNS/k29_mimicraw_47_agent_error_metrics_v29.json` |
| **1.6pct v29** | 数值感知 | 保留 | **0.993843** | **0.990200** | `$RUNS/k29_mimicraw_16_agent_error_metrics_v29.json` |
| **1.6pct A 只退字符串** | 纯字符串 | 保留 | **0.993247** | **0.988637** | `$RUNS/k29_mimicraw_16_agent_error_metrics_v29_str.json` |
| A 只退字符串 | 纯字符串 | 保留 | **0.993962** | **0.870933** | `…_v29_str.json` |
| C 只退旧开关 | 数值感知 | 全退 | **0.759609** | **0.746115** | `…_v29_oldsw.json` |
| B 完全老口径 | 纯字符串 | 全退 | **0.758576** | **0.686479** | `…_v29_old.json` |

- **退旧开关掉 0.23 是纯口径假象**（`b_missing` 82,371 → 4,718,440：agent 正确删掉、gold 里也没有的行被算成漏检）。
- **退字符串比对掉 Rep 0.108 是「写法税」**：注入 log 存注入器原始字符串（`'0'`、`'160'`），
  gold 与 agent 输出都是 python float repr（`'0.0'`、`'160.0'`）
  ⇒ 134.9 万个「数值修对了、只是写法不同」的格被老口径记成没修好。**与清洗质量无关。**
- ⚠️ **「写法税」在两档之间差 60 倍**，因为两次 agent 的输出风格不同：

| 档位 | Rep F1（数值感知 → 纯字符串） | b_clean 变化 |
|---|---|---:|
| 4.7pct | 0.978995 → **0.870933**（−0.108） | −134.9 万格 |
| **1.6pct** | 0.990200 → **0.988637**（−0.0016） | **−0.79 万格** |

  ⇒ **老口径罚的是「写法不统一」，不是「没修好」** —— 4.7pct 那次 agent 把大量值改对但
  统一成了 float repr，与 gold 的原始字符串不一致；1.6pct 这次几乎没重排格式。
- ⚠️ **历史账本（`评测总表.md` §1.2 那 16 行 A/B/C/D）全部是 v29 口径 + 数值感知** ——
  铁证：历史 `icu5000_less_agent_error_metrics_old.json` 的 `natural_noise` 与它的 v29 版逐位相同
  （9,974,997），而 k29 一切到字符串 `natural_noise` 就 45 → 936,917
  ⇒ **「小数点也算」这根轴历史上从未打开过**，本次是第一次。

## 复现命令（k29 mimicraw 4.7pct 那一行）

```bash
# 1) 造数据集 + 校验（17 项自检）
python3 reproduction/build_k29_mimicraw_error.py --src <源数据集> --dst <目标数据集> --splits test
python3 reproduction/verify_k29_mimicraw_error.py --src <源数据集> --dst <目标数据集>

# 2) 造 agent 视图（防泄漏）+ 生成 prompt + 把 prompt 放进数据集
#    （下面这条脚本把 ①②③④ 全包了：manifest / 视图 / prompt / prompt 同步进数据集）
bash scripts/prepare_k29_mimicraw_run.sh 47
#    拆开跑就是：
#    python3 reproduction/make_agent_view.py      --src <目标数据集> --dst <扣留视图>
#    python3 reproduction/make_k29_mimicraw_prompt.py --dataset <目标数据集> --out <prompt.md>

# 3) 跑
bash scripts/run_val_harness_k29_mimicraw.sh  v1   # 参数 = 实验目录后缀 v1/v2/…
bash scripts/run_test_harness_k29_mimicraw.sh       # 无参数，纯重放 val 的 best_snapshot

# 4) 评分
bash scripts/score_k29_mimicraw_agent_err.sh          # v29 错误级指标
python3 reproduction/eval_native_cells.py \
    --dataset <目标数据集> --result <结果包> --split test \
    [--string-compare]                                  # 加这个 = 老口径（纯字符串）
```
