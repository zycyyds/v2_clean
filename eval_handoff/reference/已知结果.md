## 观察到的规律（换数据集时可能复用）

1. **outputevents 双方都卡在 ~0.585** —— charttime 被哨兵值摧毁且原始值无迹可寻，
   是信息上限，不是 agent 能力问题。
2. **demographics 的 anchor_age 谁都修不回来**（整列 999 覆盖，真值无来源）。
   1.6pct codex 0.0199 / agent 0.0000；4.7pct codex 0.5594 / agent 0.5518
   （这里 0.55 是整表分，不是 age 列分）。
3. **chartevents（3,300 万行）两边几乎打平** —— 逐 cell 修复规则是可学的。
4. **行级筛选规则是分水岭** —— 错误率一高（4.7pct），agent 在
   labs/medications/procedures/diagnoses/inputevents 上掉分，这些全靠筛选规则切表。
