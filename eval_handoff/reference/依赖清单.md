# 依赖清单 —— 换机器时需要一并拷贝的东西

## ⚠️ 关键前提

**这个仓库的 git 版本控制是不完整的。** `git ls-files` 只跟踪了 125 个文件，
而评测链路上的核心文件**全都不在 git 里**：

| 文件 | 在 git 里？ | 说明 |
|---|---|---|
| `agent/pi_harness.py` | ❌ | val harness 主体（~1100 行） |
| `agent/pi_test_harness.py` | ❌ | test harness 主体（~1000 行） |
| `agent/pi_harness_cli.py` | ❌ | val 阶段 CLI |
| `agent/pi_test_harness_cli.py` | ❌ | test 阶段 CLI |
| `agent/pi_test_preflight_cli.py` | ❌ | preflight CLI |
| `agent/pi_test_scorer.py` | ❌ | 打分入口 |
| `agent/pi_harness_sandbox.py` | ❌ | macOS sandbox profile 生成 |
| `agent/pi_worker.py` | ❌ | pi worker |
| `agent/pi_worker_client.py` | ❌ | worker 客户端（JSONL over stdio） |
| `workflow/pi_harness_evaluation.py` | ❌ | **Raha 评分核心**（composite_score 怎么算的） |
| `evaluation_manifests/*.json` | ❌ | 每个任务的主键定义 |
| `reproduction/build_eval_cache.py` | ❌ | 错误级指标的缓存构建 |
| `reproduction/compute_error_metrics.py` | ❌ | 错误级指标核心 |

**所以本交付包是「实体文件交付」，不是「clone 仓库就能跑」。**
要在新机器上跑，必须把这些文件一并带过去。

## 必拷清单（从源仓库拷）

```bash
SRC=/path/to/v2_clean

# 1) harness 与评分（缺了跑不了）
mkdir -p "$DST/agent" "$DST/workflow" "$DST/evaluation_manifests" "$DST/reproduction"
cp "$SRC"/agent/pi_harness*.py          "$DST/agent/"
cp "$SRC"/agent/pi_test_*.py            "$DST/agent/"
cp "$SRC"/agent/pi_worker*.py           "$DST/agent/"
cp "$SRC"/workflow/pi_harness_evaluation.py "$DST/workflow/"
cp "$SRC"/evaluation_manifests/*.json   "$DST/evaluation_manifests/"

# 2) 错误级指标（本包 reference/ 里已有等价物，可不拷）
cp "$SRC"/reproduction/build_eval_cache.py    "$DST/reproduction/"
cp "$SRC"/reproduction/compute_error_metrics.py "$DST/reproduction/"

# 3) 已跟踪的依赖（git clone 就有了）
#    agent/__init__.py, agent/bounded_memory.py, agent/planner_agent.py,
#    agent/system_prompt.py, agent/two_phase_agents.py
#    workflow/__init__.py, workflow/agent_runners.py, workflow/bundle.py,

```

## 运行时依赖

| 依赖 | 版本/要求 | 说明 |
|---|---|---|
| conda 环境 | `py311agent2` | Python 3.11 |
| macOS | 必需 | harness 用 `sandbox-exec` 做隔离，**Linux 上跑不了** |
| 模型 API | `model_config.yaml` 里配 | **不要把 key 写进交付文件** |
| 内存 | ≥ 16 GB | 4.7pct test 重放峰值 ~5 GB |
| 磁盘 | ≥ 30 GB | test raw 5.3 GB + 结果包 + 错误分缓存 |

**Python 包**（从 `environment.yml` 看，但实测用到）：
`pandas`、`numpy`、`pyarrow`（或 `polars`）、`requests`。
